## 🚀 Featured projects

### 🗂️ [Virtual Manager](https://github.com/mihaicirlugea/virtual-manager-aspnet-mvc)
A web app that groups your **tasks** and your **money** under "ecosystems" (areas of life or projects) and shows a dashboard with charts. Login and roles with ASP.NET Core Identity, CRUD for ecosystems, activities and transactions, layered architecture (controllers → services → repositories → EF Core).
`ASP.NET Core MVC` `Identity` `EF Core` `SQLite` `Chart.js`
*Status: working prototype. The README lists the known issues and the roadmap.*

### ⚡ [K-Means: CPU vs GPU](https://github.com/mihaicirlugea/kmeans-cpu-vs-gpu-benchmark)
A benchmark of K-Means on 100k, 1M and 5M points with scikit-learn (CPU) and RAPIDS cuML (GPU). The GPU only clearly wins at 5M points on this 2-D data, and the README explains why my first measurements were misleading (cold start, mixed hardware, single runs) and how I plan to fix them.
`Python` `scikit-learn` `RAPIDS cuML` `Google Colab`
*Status: work in progress.*
